# Drystone - Opensource choice-based story/game creator
#### Editor
The editor is the way in which you can create applications for Drystone, it will allow you to create applications, scenes, choices, variables and conditional logic, applications are exported from the editor as a zip file. This zip file can then be used in the player to play through the content.

#### Player
The player can take a zip file or remote location and load its contents as an application the viewer can read/play.
